# Contributing to eos-mcp-server

## External contributions

### Skills exception

External contributions that modify only files under `skills/` may be accepted
without a contributor license agreement. By submitting such a contribution for
inclusion, the contributor licenses it under the Apache License, Version 2.0.
Arista Networks, Inc. may distribute those contributions under Apache-2.0, but
does not receive a right to relicense them under proprietary terms.

If a pull request changes `skills/` and any file outside that directory, the
contributor license agreement requirement below applies to the entire pull
request.

### All other contributions

Before Arista Networks, Inc. can accept an external contribution, the
contributor must have a written contributor license agreement with Arista that
expressly permits Arista to distribute and relicense the contribution. Do not
submit a pull request until that agreement is in place; open an issue first to
coordinate the process.

Absent a separate written agreement, contributions outside `skills/` are not
accepted for inclusion in this repository.

## License of accepted contributions

All accepted contributions are included in released versions under the Apache
License, Version 2.0. For contributions outside `skills/`, the contributor
agreement governs Arista's additional rights, including the ability to offer
future versions under different terms.
